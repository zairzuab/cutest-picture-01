An entry for make.fun's "Make the cutest picture" bounty. A tiny fluffy ginger kitten with huge amber eyes, head tilted, one paw raised toward a ball of pale yellow yarn, sitting on a cream knitted blanket against a plain warm background. A Python 3.13 program copies the picture (`cute.png`, 1024x1024) to `/output/entry.png`. Deterministic, standard library only, no network.

Run it locally: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py`, then open `out/entry.png`.
