An entry for make.fun's "Make the cutest picture" bounty. A tiny fluffy cream kitten with huge blue eyes and a daisy crown gently hugging a fluffy yellow chick, both with big bright eyes, sitting together on a cream knitted blanket against a plain warm background. The picture is stored as base64 in `cute.b64` (800x533 JPEG); a Python 3.13 program decodes it and writes it to `/output/entry.png`. Deterministic, standard library only, no network.

Run it locally: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py`, then open `out/entry.png`.
